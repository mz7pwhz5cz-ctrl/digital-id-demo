# Digital ID Demo - prywatne zaproszenie

To jest demonstracyjny mockup. Nie jest dokumentem urzędowym i nie powinien być przedstawiany jako prawdziwy dokument.

## Ważne o prywatności

Kod zaproszenia w tej wersji działa tylko jako blokada interfejsu w przeglądarce. Nie jest prawdziwym uwierzytelnianiem serwerowym. Nie wpisuj do tej wersji prawdziwych danych osobowych.

Jeśli aplikacja ma być naprawdę prywatna dla jednej osoby, opublikuj ją za usługą z prawdziwym uwierzytelnianiem / kontrolą dostępu (np. Cloudflare Access, prywatny hosting z logowaniem albo aplikacja z backendem).

## Uruchomienie

Otwórz `index.html`.

Kod demo: `zaproszenie-2026`

Przed publikacją zmień kod w `app.js`, ale pamiętaj, że sam frontend nie ukrywa kodu przed osobą techniczną.
